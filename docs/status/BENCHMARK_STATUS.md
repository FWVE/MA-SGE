# Benchmark scope

Last verified: 2026-09-26.

This is a framework-only distribution. It contains no benchmark releases,
query-generation pipeline, gold answers, raw datasets, offline evaluator,
experimental ablations, or historical model results.

Preparing this distribution did not modify the research project's benchmark
files or canonical releases. Their release status and hashes are maintained with
that research project; this repository does not duplicate its inventory.

The framework consumes user-supplied public text graphs. Local regression
fixtures test execution behavior and are not an accuracy benchmark. No accuracy,
F1, speed, or call-saving claim is made for this release package.
